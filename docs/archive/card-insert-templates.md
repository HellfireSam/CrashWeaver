# Card Insert Templates

This file is an example catalog only. It does not define schema contracts.

## Template A - Concept Card

Use for foundational definitions and conceptual explanations.

## Template B - Process Card

Use for ordered procedures with deterministic steps.

## Template C - Fact or Formula Card

Use for short factual references, formulas, constants, or lookup tables.

## Template D - Comparison Card

Use for tradeoff analysis between alternatives.

## Template E - Q and A Drill Card

Use for active recall prompts and short-answer reinforcement.

## Template F - Minimal Card

Use for fast capture with minimal fields before later enrichment.

## Notes

- Keep UID stable across note boundaries and card JSON.
- Future Weaver planning may use these template families as prompt or proposal hints, but they do not define insert behavior or approval rules.
- Keep this file as examples only. For the current schema see [`docs/reference/card-schema.md`](../reference/card-schema.md).
