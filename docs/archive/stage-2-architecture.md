# Stage 2 Architecture

## Stage Goal

Implement first complete vault workflow and note-editor shell.

## Delivered

- Open vault folder
- Read and write markdown notes
- Refresh .crashweaver/index.json (note-level)
- Explorer tree plus source and preview modes with math rendering

## Stage Boundary

Stage 2 is note-centric. Card boundary parsing, card-store sync, and crashpad workflows are out of scope for this stage.
