# Documentation archive

Everything in this folder is **superseded**. These documents were written during the
project's staged build-out and are kept only as a record of what was believed at the
time. They are not maintained, they carry no authority, and several of them contradict
each other and the code.

Current documentation:

- [Documentation index](../README.md)
- [Domain glossary](../../CONTEXT.md)

Every archived document carries a superseded banner at the top. File names were changed
to kebab-case when the documents moved here; the content is otherwise unedited except
for removed deference headers and reference paths repaired to point inside the archive.
